# SC-1 source-view evaluation — ai-pipe

Date: 2026-08-07

## Decision

Keep full source as the default. The current deterministic elider did not
reduce any selected artifact in the elided arm, while both arms answered all
four tasks correctly. The observed elided arm also made more tool calls,
returned more tool and source bytes, inspected more irrelevant files, and took
longer. This rejects the current renderer; it does not reject source elision as
a design direction.

Before another agent run, benchmark full and elided rendering over the same
paired artifacts. Shorten or restructure elision markers until that benchmark
shows a material deterministic byte reduction while preserving the required
signatures, branches, calls, loops, returns, and throws.

## Corpus and protocol

- Repository: `ai-pipe`
- Frozen source commit: `ea13166c59cfc52574e96959413f5c54be20e8c8`
- Indexed JS/TS files: 690
- Chunks: 5,483
- References: 28,527
- jscout snapshot:
  `93fc29f5b7260c604d0e6d426420437921267ddda7f5eb5e8ebadbf8da2a4b86`
- Agent: Codex CLI `0.141.0`, `gpt-5.4`, low reasoning
- Tasks: four fixed structural questions from the P0 set
- Trials: one run per task/view; view order counterbalanced by task
- Grading: exact set equality for production files and symbols
- Controlled difference: MCP `definition` source view only
- Shared source ceiling: 12,000 bytes per definition artifact
- Prompt contract: start with jscout and verify every final named symbol with
  `definition`

The previously used `gpt-5.6-terra` was unavailable in the installed CLI, so
this run used `gpt-5.4`. Results are not directly comparable to the P0 agent
cost or latency numbers.

## Result

| Metric, mean per task | Full | Elided | Elided − full |
|---|---:|---:|---:|
| Exact correctness | 4/4 | 4/4 | 0 |
| jscout calls | 8.75 | 10.25 | +1.50 |
| Tool result bytes | 44,294.75 | 57,858.25 | +13,563.50 |
| Definition source rendered bytes | 7,868.75 | 12,891.25 | +5,022.50 |
| Definition source original bytes | 9,427.50 | 12,891.25 | +3,463.75 |
| Source budget truncations | 0.75 | 0.00 | -0.75 |
| Inspected files | 9.50 | 14.25 | +4.75 |
| Irrelevant inspected files | 6.00 | 10.75 | +4.75 |
| Agent tokens | 231,361.75 | 219,721.25 | -11,640.50 |
| Wall time | 46.268 s | 53.539 s | +7.271 s |

Every elided artifact selected during the run reported rendered bytes equal to
original bytes. The renderer correctly declined to replace source spans when
its explicit elision marker would be longer than the removed text, but that
means it provided no compression in this workload.

## Limits

- One run per task/view cannot establish stable call, token, or latency deltas.
- Agents selected different definition calls in the two arms. Aggregate source
  bytes therefore measure product behavior, not compression of identical
  artifacts.
- Both arms remained at the correctness ceiling, so this run only gates payload
  behavior.
- The task prompt forced definition use to expose the source representation. It
  does not measure natural definition-tool selection.

The next SC-1 measurement must first pair identical artifacts, then repeat the
agent comparison only if the renderer clears a predeclared compression floor.
